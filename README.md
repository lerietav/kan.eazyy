# 🎀 kan.eazyy

**One task at a time.** ✨

kan.eazyy es una aplicación web de gestión de tareas basada en la metodología Kanban, diseñada para organizar actividades de manera visual, sencilla y eficiente. Permite dar seguimiento al progreso de las tareas mediante un tablero dividido en cinco columnas, desde las actividades pendientes hasta las completadas.

## ✨ Características

- **Tablero Kanban:** organización de tareas en Backlog, To Do, In Progress, Testing y Done.
- **Gestión de tareas:** creación, edición y eliminación de tarjetas.
- **Seguimiento del progreso:** actualización del estado de las tareas mediante el tablero.
- **Información de las tarjetas:** visualización de título, descripción, responsable, prioridad y fecha límite.
- **Búsqueda y filtros:** localización de tareas según los criterios disponibles en la aplicación.
- **Límites WIP:** control del trabajo en proceso, con límites configurados para To Do (5), In Progress (3) y Testing (2).
- **Almacenamiento local:** persistencia de la información en el navegador mediante localStorage.
- **Interfaz visual:** diseño minimalista en tonos rosa y blanco.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Ejecuta el archivo `index.html` en un navegador o utiliza la extensión Live Server.
4. Explora las funciones del tablero y prueba la gestión de tareas.

## 🎯 Objetivo del proyecto

Desarrollar una herramienta digital que facilite la organización y el seguimiento de actividades mediante un tablero Kanban, aplicando conceptos de desarrollo web, manipulación del DOM, gestión de eventos y almacenamiento de datos en el navegador.

## ⚠️ Consideraciones

Este proyecto tiene fines académicos y utiliza almacenamiento local. Los datos no se sincronizan automáticamente entre dispositivos o usuarios. El inicio de sesión y el registro son demostrativos y no constituyen un sistema de autenticación seguro.
